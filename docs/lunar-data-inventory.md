# lunar-typescript 데이터 인벤토리

> probe(`my-app/probe.mjs`)로 실측한 라이브러리 출력 정리. 와이어프레임 그릴 때 "이 블록엔 이 데이터" 참고서.
> 라이브러리: `lunar-typescript@1.8.6` (6tail), 의존성 0
> 테스트 생일: 1990-02-03 22:58 남자 (진태양시 보정 전)

---

## 1. 원국(사주 8자) — 라이브러리가 바로 주는 것

| 항목 | 메서드 | 실측 출력 | 비고 |
|---|---|---|---|
| 연주 | `getYear()` | `己巳` | 두 글자(천간+지지) |
| 월주 | `getMonth()` | `丁丑` | |
| 일주 | `getDay()` | `己亥` | |
| 시주 | `getTime()` | `乙亥` | |
| 일간(나 자신) | `getDayGan()` | `己` | 해석 기준점 |
| 기둥별 오행 | `getYearWuXing()` 등 | `土火` | **천간오행+지지오행 두 글자 붙어서 옴 → 한 글자씩 분리 필요** |
| 십신(천간) | `getYearShiShenGan()` | `比肩` | 문자열 1개 |
| 십신(지지) | `getDayShiShenZhi()` | `[ '正财', '正官' ]` | **배열** (지지 안 지장간마다) |
| 지장간 | `getDayHideGan()` | `[ '壬', '甲' ]` | **배열** — 오행 비율 셀 때 포함 |

## 2. 흐름/기간 — 라이브러리가 주는 것

| 항목 | 메서드 | 실측 출력 | 비고 |
|---|---|---|---|
| 대운(10년) | `getYun(성별).getDaYun()` | 배열 10개, 각 `getStartAge()`=20, `getGanZhi()`=`乙亥` | 성별: 남 1 / 여 0. 흐름 그래프 재료 |
| 오늘 일진 | `Solar.fromDate(new Date()).getLunar().getDayInGanZhi()` | `辛亥` | 오늘 운세 |
| 올해 세운 | `...getYearInGanZhi()` | `丙午` | 올해 운세 |
| 이번달 월운 | `...getMonthInGanZhi()` | `乙未` | 절기 기준 월건 |

---

## 3. ⚠️ 중요 발견

1. **간체(简体)로 출력됨** — `正财`의 `财`는 간체. 번체 `財` 아님.
   → 한글 매핑 표의 **키를 반드시 간체 글자로** 잡아야 함 (財 X, 财 O).
2. **기둥 오행이 2글자 문자열** — `土火` 처럼 붙어 나옴. 오행 개수 집계 시 한 글자씩 쪼갤 것.
3. **지지 십신 / 지장간은 배열** — 개수가 가변.

---

## 4. 라이브러리가 안 주는 것 = 내 가공 몫

| 만들 것 | 재료 | 방법 |
|---|---|---|
| 오행 비율 % | 8자 오행 + 지장간 | 목화토금수 5버킷 카운트 → % |
| 상생상극 점수 | 일간 vs 각 간지 | 기획서 §10 점수표(+2 ~ −2) |
| 간체→한글 매핑 | 천간10·지지12·오행5·십신10 | 고정 상수 테이블(~40개) |
| 진태양시 보정 | 입력 시각 | 서울 기준 −32분 (입력 전처리, 아직 미적용) |

---

## 5. 화면 블록 ↔ 데이터 매핑

| 화면 블록 | 라이브러리 소스 | 내 가공 |
|---|---|---|
| 원국표 8칸 | `getYear/Month/Day/Time()`, 오행, 십신 | 간체→한글 |
| 오행 도넛 | 기둥 오행 + `getDayHideGan()`(지장간) | 개수 세서 % |
| 흐름 그래프 | `getDaYun()` (나이+간지) | 간지→상생상극 점수화 |
| 기간 운세 카드 | `getDayInGanZhi()` 등 | 일간과 상생상극 점수 |
| 원국표 십신 라벨 | `getYearShiShenGan()`, `getDayShiShenZhi()` | 간체→한글 |
